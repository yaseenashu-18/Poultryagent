## Brand & Style

This design system embodies the clinical precision, speed, and reliability of cutting-edge voice intelligence tailored for enterprise operations across diverse service verticals (Lost & Found, Marketplace, Rentals, On-Demand Services, and Community Giveaways).

### Design Archetype
**Technical Minimalism with Precision Telephony Accents.** The visual language eliminates visual friction and superfluous decoration. It leverages crisp hairline structures, high-legibility typographic hierarchies, restrained sapphire accents, and real-time operational status signals.

### Emotional Target
- **Instant Confidence:** Uncompromising responsiveness, rock-solid uptime, and enterprise-grade data governance.
- **Acoustic Clarity:** Interface surfaces feel clean and transparent, evoking noise-free, high-fidelity audio streams.
- **Instrument Precision:** Dense telemetry presented cleanly through balanced whitespace, monospaced computational metrics, and crisp micro-indicators.

## Colors

The palette is engineered for prolonged operational focus, high data density, and clear auditory-state identification.

### Primary & Action
- **Primary Sapphire (`#2563EB`)**: High-priority interactive triggers, active tab indicators, and agent routing highlights.
- **Primary Deep (`#1D4ED8`)**: Hover and pressed states for primary controls.
- **Primary Subtle (`#EFF6FF`)**: Focus halos, badge backgrounds, and selected table row washes.

### Secondary & Surface Chrome
- **Deep Slate / Carbon (`#0F172A`)**: Primary headers, prominent counters, and active high-contrast tokens.
- **Slate Body (`#1E293B` / `#334155`)**: Body copy, modal context, and secondary metric labels.
- **Slate Muted (`#64748B`)**: Metadata labels, input placeholders, and inactive icons.

### Status & Audio Telemetry
- **Live Active Emerald (`#10B981`)**: Active call streams, real-time voice latency below 400ms, and operational health nodes.
- **Emerald Wash (`#ECFDF5`)**: Background for live voice status badges and audio monitoring bars.
- **Warning Amber (`#F59E0B`)**: Call transfer thresholds, packet jitter, and verification alerts.
- **Destructive Rose (`#EF4444`)**: Dropped calls, quota exhaustion, and disconnect triggers.

### Canvas & Structural Borders
- **Canvas Base (`#F8FAFC`)**: Application backdrop behind modular grids.
- **Surface Elevation 0 (`#FFFFFF`)**: Primary cards, call logs, canvas sidebars, and control panels.
- **Border Structural (`#E2E8F0`)**: Hairline 1px dividers, card perimeters, and container splits.
- **Border Subdued (`#F1F5F9`)**: Internal table horizontal grid lines and nested section splitters.

## Typography

The typographic hierarchy uses **Geist** for crisp structural reading and **JetBrains Mono** for all numerical, latency, audio duration, and telephony log readouts.

### Scaling & Rendering
- **Negative Letter Spacing:** Applied intentionally from `headline-sm` upward to tighten headlines for a precise, modern editorial finish.
- **Tabular Figures & Metrics:** Every latency meter, SIP duration stamp, confidence score, and phone dialer utilizes `data-mono-sm` or `data-metric` with tabular alignment (`font-variant-numeric: tabular-nums`) to prevent layout shifts during live audio playback.

## Layout & Spacing

The layout is built upon an adaptive 12-column desktop grid with persistent 240px utility navigation and expandable context drawers for live call inspect logs.

### Grid & Breakpoints
- **Desktop (1280px+)**: 12 columns, `margin: 2rem`, `gutter: 1.5rem`. Max-width content canvas locked at 1600px to ensure dense supervisory dashboards remain readable without visual dissociation.
- **Tablet (768px - 1279px)**: 8 columns, `margin: 1.5rem`, `gutter: 1rem`. Audio visualizer and transcript inspector stack vertically into an overlay panel.
- **Mobile (< 768px)**: 4 columns, `margin: 1rem`, `gutter: 0.75rem`. Live call controls convert into sticky bottom sheets.

### Spatial Rhythm
Padding relies strictly on multiples of 4px. Operational interfaces (such as call logs, prompt testing sandboxes, and waveform panels) favor compact row heights (36px to 44px) to maximize visible telemetry.

## Elevation & Depth

This design system avoids heavy drop shadows, relying instead on structural 1px borders paired with subtle ambient diffusion.

### Elevation Levels
- **Layer 0 (Canvas):** Pure `#F8FAFC` background. Completely flat.
- **Layer 1 (Card/Container):** Pure `#FFFFFF` surface framed by a 1px solid `#E2E8F0` hairline border. Shadow: `0 1px 2px 0 rgba(15, 23, 42, 0.04)`.
- **Layer 2 (Dropdowns, Popovers, Telephony Menus):** Pure `#FFFFFF` surface with `1px solid #CBD5E1`. Shadow: `0 4px 12px -2px rgba(15, 23, 42, 0.08), 0 2px 4px -1px rgba(15, 23, 42, 0.03)`.
- **Layer 3 (Modals, Active Call Audio Inspector):** `#FFFFFF` surface with `1px solid #94A3B8`. Shadow: `0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.05)`.
- **Active Real-Time Glow (Live Streams):** Radial ambient highlight behind active audio waveforms: `0 0 16px -2px rgba(16, 185, 129, 0.25)`.

## Shapes

The geometric framework is calibrated at level `2` (0.5rem / 8px core radius), conveying software precision and enterprise durability.

### Curvature Matrix
- **Core Components (Buttons, Input Fields, Badges, Tabs):** `8px` (`0.5rem`) for high-precision tactile fit.
- **Cards, Audio Panels, Waveform Containers:** `12px` to frame internal content gracefully.
- **Telephony Status Indicators & Voice Frequency Bars:** Fully rounded (`9999px` / pill) to denote variable sound waves and ongoing calls.

## Components

### Buttons
- **Primary:** Background `#2563EB`, text `#FFFFFF`, 8px radius, height 36px (compact) or 40px (default). On hover: `#1D4ED8`. Active state scales subtly (`scale-98`). Focus: `2px solid #2563EB` offset by `2px`.
- **Secondary / Outline:** Background `#FFFFFF`, border `1px solid #E2E8F0`, text `#1E293B`. On hover: background `#F8FAFC`, border `#CBD5E1`.
- **Ghost:** Background transparent, text `#64748B`. On hover: `#F1F5F9`, text `#0F172A`.
- **Live Call Action (Hangup / Mute):** Hangup uses `#EF4444` background with white icon; Mute uses `#F1F5F9` with `#0F172A` text.

### Telephony Indicator Badges & Chips
- **Live Stream Badge:** Background `#ECFDF5`, border `1px solid #A7F3D0`, text `#065F46`. Houses a 6px pulsating `#10B981` dot.
- **Service Classification Chips:** Distinctive muted tags for the 5 Foundify modules:
  - *Lost & Found:* Slate tint (`#F1F5F9`, text `#334155`).
  - *Marketplace:* Indigo wash (`#EEF2FF`, text `#4338CA`).
  - *Rentals:* Sky wash (`#F0F9FF`, text `#0369A1`).
  - *Services:* Amber wash (`#FEF3C7`, text `#92400E`).
  - *Giveaways:* Emerald wash (`#ECFDF5`, text `#065F46`).

### Waveform Visualizer & Audio Bars
- Built with arrays of 3px-wide pill bars spaced by 2px. Inactive segments use `#E2E8F0`; active stream outputs dynamically scale bar heights using `#2563EB` and `#10B981`.

### Data Tables & Call Logs
- **Header:** Height 36px, uppercase `label-sm` tracking with `#64748B`, background `#F8FAFC`, bottom border `1px solid #E2E8F0`.
- **Rows:** Height 48px, horizontal dividers `1px solid #F1F5F9`, hover background `#F8FAFC`. Columns include Caller ID, Voice Model (e.g., ElevenLabs / Retell Engine), Foundify Service Category, Duration (`data-mono-sm`), and Latency Score.

### Input Fields & Prompt Editor
- **Inputs:** Height 40px, border `1px solid #E2E8F0`, background `#FFFFFF`, text `#0F172A`, placeholder `#94A3B8`. Focus ring: `2px solid #2563EB` with `0px offset`.
- **System Prompt Sandbox:** Rich monospaced textarea (`JetBrains Mono`), background `#FFFFFF`, line numbering column in `#F8FAFC` with `#94A3B8` numerals.

### Cards
- Pure `#FFFFFF` background, `1px solid #E2E8F0` perimeter, 12px corner radius, internal padding `space-md` or `space-lg`. Metric cards prominently feature a `label-sm` title, a `data-metric` figure, and a subtle trend chip.
